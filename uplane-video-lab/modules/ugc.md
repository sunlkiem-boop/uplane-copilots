# UGC
> Looks like a real person filmed it on their phone. Never AI-slick, never a commercial.

## Checklist
- Camera: handheld with tiny shakes and casual reframes, slightly imperfect framing
- Focus: deep phone focus on everything, no blurry professional background
- Look: faint grain, soft compression, true-to-life slightly muted color
- Between clips: small exposure differences, like clips shot at different times of day
- Skin and objects: real texture, never airbrushed, waxy, or plastic-looking
- Settings: ordinary phone lighting, nothing staged for a shoot
- Never: CGI, animation, cinematic, polished, color-graded, tripod-steady

## For the prompt writer
Weave these into FORMAT AND CAMERA and restate the hard ones in the anti-AI
rules list. Close with the failure condition: "If it looks like a tripod
commercial, it is wrong." Remind in POST notes: if the render still looks too
clean, run the de-polish pass (grain + color correction).
