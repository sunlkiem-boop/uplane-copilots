# One product, perfect label
> One unit per product variant on screen, each label copied exactly from its own product photo.

## Checklist
- The SAME unit(s) in every clip, identical size and label throughout
- Never duplicate units of the same variant, never a pack, box, or row
- If the plan calls for two flavors/variants, exactly one of EACH, clearly distinct, each matching its own attached reference image
- Front label toward the camera at all times: never the back, never spinning
- Close enough that the label text stays sharp and readable
- Labels reproduced exactly: shape, colors, badges, every word spelled right
- No typos, no invented words, no warped or restyled lettering

## For the prompt writer
This is the PRODUCT REFERENCE IMAGE block and the PRODUCT block. Default is
ONE unit of ONE variant. When the reviewer's notes ask for multiple variants
(e.g. chocolate and vanilla side by side), write one reference-image binding
per variant ("the chocolate can matches the first attached image, the vanilla
can the second"), describe each label separately in the PRODUCT block, and
remind that one image per variant will be attached. Close with: "Match each
attached reference image exactly." Anti-AI rule: "If an extra duplicate unit
appears or any label garbles, it is wrong."
